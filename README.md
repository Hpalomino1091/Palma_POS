# Palma POS

Landing page para Palma POS, un sistema de punto de venta. Hecha con React 19, Vite, Tailwind CSS v4, GSAP y Lucide.

**Demo:** https://hpalomino1091.github.io/Palma_POS/

## Ejecutar en local

```bash
npm install
npm run dev
```

## Publicación

Cada `push` a `main` compila el sitio y lo publica en GitHub Pages con el flujo de `.github/workflows/deploy.yml`.
